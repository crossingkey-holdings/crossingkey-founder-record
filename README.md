## Founder thesis

The recurring focus of the work is the layer between **human intent and machine execution**: context, permissions, state, tools, failure handling, observability, verification, and human authority.

The public engineering principle used across the surface is:

> **Capability does not imply authority.**

## Evidence standard

- **Completed:** a public artifact or dated evidence exists.
- **Active:** work is underway and is not represented as released.
- **Planned:** direction only; no delivery claim.
- **Historical production claim:** a record of an event or deployment that is not represented as independently re-verified today.

Corrections should preserve the record rather than silently rewrite it.
